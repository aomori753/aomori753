# Asset sources and usage — Rebrand V2

Reviewed 25 September 2026. This record distinguishes source licensing from trademark permission; it does not change the repository-wide license or assert ownership of third-party marks.

## Original profile artwork

The jo. mark, four header SVGs, ten project-card SVGs and five category symbols (`sql`, `code`, `workflow`, `terminal`, `assistant`) were drawn specifically for this local profile candidate. They contain self-contained geometry and, in display art, safe system-font text. No reference image, font binary, photograph, proprietary screenshot, remote resource or generated performance result is embedded.

The PNG header fallback is a direct raster rendering of the light header SVG. Its permitted image chunks are checked by the repository checker. Original SVG title/description fields contain public presentation descriptions, not local machine or author metadata.

The `assistant` symbol is an original generic category icon, **not** an OpenAI, Anthropic or Google mark. ChatGPT, Codex, Claude and Gemini/Google AI Studio appear as text in their appropriate workflow/provider contexts. No partnership, certification or endorsement is implied.

## Maintenance

Keep credits near this permanent record and retain the candidate's icon-credit link. Inspect any replacement mark and its current source guidance before adding it; a familiar product name is not enough. Use the smallest relevant icon set, preserve truthful usage context and do not add official AI-tool logos merely for visual density.
