## What V2 should restore

- A personal, visual opening with concise identity and restrained navigation.
- Recognizable technology marks arranged in a few meaningful groups.
- Clear visual breaks between experience, current work, research and development.
- Selected projects and their evidence near the opening.
- A compact initial reading path, with complete supporting text in labelled disclosures.

The old terminal animation, activity counters, remote statistics, broad compliance badges and undifferentiated badge wall are not part of the restoration. Local artwork and licensed local icons provide the visual function within the current GitHub and privacy constraints.
